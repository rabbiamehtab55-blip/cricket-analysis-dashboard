# 🏏 Cricket Analysis Dashboard

An interactive Cricket Analysis Dashboard built using **Python, Pandas, Plotly, and Streamlit**. The dashboard provides an easy and interactive way to explore Test cricket player career statistics and performance.

## 🚀 Live Dashboard

👉 **[View Live Cricket Analysis Dashboard](https://cricket-analysis-dashboard.streamlit.app/)**

## 📌 Project Overview

This project analyzes cricket player career statistics and converts raw data into meaningful and interactive visual insights.

Users can explore player performance, compare players, analyze country-wise statistics, and filter the dataset based on different performance measures.

## 🎯 Project Objectives

- Analyze cricket player career performance
- Compare the statistics of different players
- Explore country-wise cricket statistics
- Identify high-performing players
- Create interactive data visualizations
- Make cricket statistics easier to understand

## 📊 Dashboard Features

### 🏠 Home
Provides an overall overview of the dataset, including:
- Total Players
- Total Countries
- Total Matches
- Total Runs
- Total Sixes
- Top Run Scorers
- Top Batting Averages

### 👤 Player Analysis
Select an individual player and explore:
- Matches
- Runs
- Batting Average
- Strike Rate
- Centuries
- Fifties
- Fours
- Sixes
- Highest Score
- Career Duration

### 🌍 Country Insight
Explore cricket statistics by country, including:
- Number of Players
- Total Runs
- Total Matches
- Total Centuries
- Top Run Scorers
- Average vs Strike Rate

### 📊 Player Comparison
Compare two players based on:
- Matches
- Innings
- Runs
- Highest Score
- Average
- Strike Rate
- Centuries
- Fifties
- Fours
- Sixes

### 📋 Data Explorer
Users can filter the dataset by:
- Country
- Minimum Runs
- Minimum Batting Average

The filtered data can also be downloaded as a CSV file.
